## Running the Website Locally

The website is built with static HTML, CSS, and
JavaScript, so no Node.js installation or build
process is required.

### Option 1: Open in a Browser

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.

### Option 2: Use Visual Studio Code

1. Clone the repository:

```bash
git clone https://github.com/Riska997/personal-portfolio-website.git
```

2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if necessary.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

The website will open in your default browser.
